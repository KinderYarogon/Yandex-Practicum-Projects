# Портфолио проектов по анализу данных

Здесь собраны мои проекты, выполненные в рамках обучения анализу данных в Яндекс Практикуме.

## Проекты

### 1. Анализ рынка заведений общественного питания Москвы

Исследование рынка заведений общественного питания Москвы. Анализ категорий заведений, их расположения, сетевой принадлежности, рейтингов, цен и других характеристик.

**Инструменты:** Python, Pandas, Matplotlib, Seaborn, Phik, Jupyter Notebook.

**Содержание проекта:** `moscow-food-service-market-analysis/`
